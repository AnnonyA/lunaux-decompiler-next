# Roadmap

## 0.1 — Foundation

- Stable backend protocol.
- Direct CLI and versioned HTTP API.
- Input and output limits.
- Cross-platform CI.
- Native compatibility adapter.

## 0.2 — Diagnostics and fixtures

- Backend capability reporting.
- Corpus metadata format.
- Golden-test normalization.
- Benchmark command and JSON reports.

## 0.3 — Open bytecode reader

- Versioned Luau bytecode parser.
- Prototype and constant validation.
- Instruction-level disassembly.
- Malformed-input fuzzing.

## 0.4 — Analysis IR

- Basic blocks and control-flow graph.
- Dominators and loop discovery.
- Register definition/use chains.
- Multiple-return and vararg modeling.

## 0.5 — Structured source

- Condition and loop reconstruction.
- Closure and upvalue handling.
- Luau AST and deterministic printer.
- Recompilation and semantic-equivalence metrics.
